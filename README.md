# Folder Watchdog

Folder Watchdog is a lightweight and portable Windows application that monitors a directory for changes in real time. It runs in the background, providing instant notifications about file or folder modifications.

Built during [Hack Club High Seas 2024](https://highseas.hackclub.com).

## Features

- Monitoring: Detects changes, additions, deletions, and renames in a specified directory.
- Subdirectories: Optionally include subdirectories in the monitoring scope.
- Customizable Filters: Filter changes based on file names or extensions.

## Getting Started

1. Download the latest release from the [Releases](https://github.com/majoouoo/FolderWatchdog/releases) Page.
2. Run the portable executable.

### Prerequisites

- Operating System: Windows 11
- Framework: Microsoft .NET Framework (ensure it's installed)
